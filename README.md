# Student CRUD API

A simple FastAPI application for managing student records using CRUD operations.

This project was built as part of the Euron Super 30 Work & Learn Portal assignment.

## Features

- Create students
- Retrieve all students
- Retrieve a student by ID
- Update student information
- Delete students
- Pydantic request validation
- Email format validation
- Age validation
- Meaningful HTTP error responses
- Interactive Swagger API documentation

## Tech Stack

- Python
- FastAPI
- Pydantic
- Uvicorn

## Data Model

Each student contains:

```text
id
name
email
age
course
```

The student ID is generated by the application.

The application uses an in-memory Python list for storage because a database was not required for this assignment.

> Note: Student data is reset when the application is restarted.

## Pydantic Validation

The application uses Pydantic to validate incoming student data.

### Name

- Minimum length: 2 characters
- Maximum length: 100 characters

### Email

The `EmailStr` type validates the email format.

### Age

Age must be between 5 and 100.

### Course

- Minimum length: 2 characters
- Maximum length: 100 characters

Invalid requests are automatically rejected by FastAPI/Pydantic.

## Setup

### 1. Clone the repository

```bash
git clone <your-repository-url>
cd student-crud-api
```

### 2. Create a virtual environment

Windows:

```powershell
python -m venv venv
```

Activate it:

```powershell
.\venv\Scripts\activate
```

### 3. Install dependencies

```powershell
python -m pip install -r requirements.txt
```

### 4. Run the application

```powershell
python -m uvicorn app.main:app --reload
```

The API will be available at:

```text
http://127.0.0.1:8000
```

Swagger UI:

```text
http://127.0.0.1:8000/docs
```

## API Endpoints

### 1. Create a Student

```http
POST /students
```

Request:

```json
{
  "name": "Arun Kumar",
  "email": "arun@example.com",
  "age": 24,
  "course": "AI Engineering"
}
```

Response:

```json
{
  "id": 1,
  "name": "Arun Kumar",
  "email": "arun@example.com",
  "age": 24,
  "course": "AI Engineering"
}
```

Status:

```text
201 Created
```

---

### 2. Get All Students

```http
GET /students
```

Example response:

```json
[
  {
    "id": 1,
    "name": "Arun Kumar",
    "email": "arun@example.com",
    "age": 24,
    "course": "AI Engineering"
  },
  {
    "id": 2,
    "name": "Priya",
    "email": "priya@example.com",
    "age": 22,
    "course": "Data Science"
  }
]
```

Status:

```text
200 OK
```

---

### 3. Get a Student by ID

```http
GET /students/{student_id}
```

Example:

```http
GET /students/1
```

Response:

```json
{
  "id": 1,
  "name": "Arun Kumar",
  "email": "arun@example.com",
  "age": 24,
  "course": "AI Engineering"
}
```

Status:

```text
200 OK
```

If the student does not exist:

```text
404 Not Found
```

```json
{
  "detail": "Student not found"
}
```

## Validation Example

The following request contains invalid data:

```json
{
  "name": "A",
  "email": "not-an-email",
  "age": 150,
  "course": "AI"
}
```

Pydantic rejects the request because:

- The name is shorter than the minimum length.
- The email is not valid.
- The age is greater than the allowed maximum.

FastAPI returns:

```text
422 Unprocessable Entity
```

with details about the validation failures.
